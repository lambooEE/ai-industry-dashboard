# AI产业链监控 Dashboard

自动化 AI 产业链信号追踪与投研可视化系统。

## 功能

- 📊 **总览**：市场情绪、板块涨跌、关键指标一览
- 🔄 **板块轮动**：四象限矩阵，直观展示板块动量与相对强弱
- 📈 **行情监控**：102只美股实时数据，支持三重筛选
- ⚠️ **风险评估**：多维度风险评分与预警
- 🌐 **中英双语**：一键切换中英文界面

## 数据源

- Wisesheets API（美股行情、财务数据）
- 多源新闻聚合（交叉验证）

## 自动更新

每周一 08:00（北京时间）自动生成最新报告并更新 Dashboard。
